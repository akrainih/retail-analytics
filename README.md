# retail-analytics
RFM-анализ интернет-магазина 

Анализ транзакций британского интернет-магазина (1 млн записей, 2009–2011).
Полный цикл: очистка данных, RFM-сегментация,
дашборд в Tableau, статистическая проверка гипотезы.

**Стек:** Python (pandas, scipy), PostgreSQL, Tableau 

## Бизнес-задача

Интернет-магазин теряет клиентов. Нужно понять:
- Кто самые ценные клиенты?
- Какие сегменты уходят? 
- Где теряется выручка?

## Ключевые инсайты

- **Champions: 31.1% клиентов - 75.8% выручки.** Это бывшие крупные 
  клиенты (медиана monetary 3011 £), которые перестали покупать.

- **At risk: 15% клиентов - 14.5% выручки.** Медиана monetary 1571 £.

## Ход работы

1. **Очистка данных** (Python, pandas):
   - Удалила отмены (Invoice с 'C') и возвраты
   - Разделила на 2 витрины: с Customer ID и без
   - Обработала 243k пропусков Customer ID

2. **SQL-витрины** (PostgreSQL):
   - Создала v_rfm с расчётом R, F, M
   - Написала 15+ запросов
   - Использовала результаты запросов для создания дашбордов

3. **RFM-сегментация**:
   - 5 878 клиентов разделены на 6 сегментов
   - Champions, Loyal, New, At Risk, Lost, Others

4. **Дашборд** (Tableau Public):
   - 2 страницы: обзор, RFM
