# retail-analytics
RFM-анализ интернет-магазина 

Анализ транзакций британского интернет-магазина (1 млн записей, 2009–2011).
Полный цикл: очистка данных, RFM-сегментация,
дашборд в Tableau, статистическая проверка гипотезы.

**Стек:** Python (pandas, scipy), PostgreSQL, Tableau 

## Бизнес-задача

Интернет-магазин теряет клиентов. Нужно понять:
- Кто самые ценные клиенты?
- Какие сегменты уходят? 
- Где теряется выручка?

## Ключевые инсайты

- **At Risk: 34% клиентов - 78% выручки.** Это бывшие крупные 
  клиенты (средний monetary 26 120 £), которые перестали покупать.

- **Champions: 12% клиентов - 13% выручки.** Средний monetary 5 963 £.
  Их надо удерживать.

- **Разница monetary между сегментами статистически значима** 
  (Mann-Whitney U, p = 2.64e-32).
